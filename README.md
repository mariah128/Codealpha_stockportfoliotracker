# Stock Portfolio Tracker

This project is a simple Stock Portfolio Tracker developed using Python.

## Features

- User enters stock names and quantities.
- Uses a predefined dictionary of stock prices.
- Calculates the total investment value.
- Saves the final result in a text file.

## Technologies Used

- Python
- Dictionary
- Loops
- Input/Output
- File Handling

## How to Run

Run the following command:

python stock_portfolio_tracker.py
